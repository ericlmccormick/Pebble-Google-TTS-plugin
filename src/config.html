Pebble plugin · Speech

Universal TTS

One speech interface for any compatible Pebble watch app. Configure and choose your default provider here; apps never receive your provider credentials.

1

Speech provider

Choose one provider as the default. You can save credentials for several providers.

OpenAI's older Speech API retires January 6, 2027. It is intentionally not included here; a future OpenAI adapter must use the Realtime API.

2

Connection

Keys and long-lived tokens are stored in Pebble secure storage, and are never shown to calling watch apps.

Private LAN HTTP or HTTPS. HTTPS is preferable; public custom hosts may require additional Pebble Internet permissions.

3

Voice & model

Voice selection is specific to each provider.

After saving your API key, live models and voices are retrieved from that provider. No cached or hard-coded catalog is used. If the provider has no listing endpoint, you can still enter a voice/model ID manually.

Select a provider to browse available voices and models.

All voices are normalized to 8 kHz mono WAV and played through the same Pebble SDK. Voice and model choices belong to the user, never the watch app.
4

Save & test

The test synthesizes a short sample and checks its audio format; it may use paid API credits. Actual watch-speaker playback must be tested in a compatible app.
